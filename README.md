# 🛡️ CyberDeebka | Enterprise Security Suite

المنظومة الاحترافية الأولى لتدقيق الأمان السيبراني واختبار الاختراق الأخلاقي، مصممة خصيصاً للمهندسين والمختصين لتوفير أدوات فحص سريعة ومتطورة للهواتف والحواسيب.

## 🚀 المميزات الرئيسية
* **30 أداة سيبرانية متقدمة:** مقسمة بدقة بين أدوات الهاتف الميدانية وأدوات الكمبيوتر العميق.
* **نفق تشفير (VPN Tunneling):** محاكاة تأمين وحماية الاتصالات عبر خوادم عالمية متعددة.
* **نظام الباقات والاشتراكات:** محفظة ذكية، باقات شهرية وسنوية، ونظام تجارب مجانية للأدوات الاحترافية (PRO).
* **تصميم متجاوب بالكامل:** واجهة مظلمة عصرية (Dark Theme) مدعومة بمكتبة Tailwind CSS وتجربة استخدام سلسة (PWA).

## 🛠️ الملفات الأساسية بالمشروع
* `index.html` - الواجهة الرئيسية وهيكل التطبيق بالكامل.
* `script.js` - محرك المنظومة وقواعد بيانات الأدوات ومنطق التشغيل والـ APIs.
* `manifest.json` - إعدادات تطبيق الويب التقدمي (PWA) للعمل كمل تطبيق على الهاتف.
* `sw.js` - خدمة الـ Service Worker للتخزين المؤقت وسرعة التحميل.
